# ✨ Overview

**Smart Cover Letter Generator** is an AI-powered career assistance platform that automatically creates personalized and professional cover letters using:
- uploaded CVs
- LinkedIn job posting URLs
- AI-powered language generation

The application analyzes:
- candidate profiles
- job descriptions
- required skills
- professional experience

to generate customized cover letters tailored specifically for the target role.

Built using:
- Python
- Streamlit
- OpenAI LLMs
- LangChain

the project simplifies the job application process through intelligent automation.

# 🧠 AI Workflow

The platform works by:
1️⃣ Uploading a CV/resume  
2️⃣ Providing a LinkedIn job URL  
3️⃣ Extracting job requirements  
4️⃣ Matching candidate skills  
5️⃣ Generating a professional cover letter  

The generated output includes:
- personalized introduction
- role-specific highlights
- relevant technical skills
- professional tone
- recruiter-friendly formatting
